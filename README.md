# Minimal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript. It is ready to publish with GitHub Pages.

## Before publishing
1. Replace every instance of `Your Name` / `YN` with your name / initials.
2. Update email, LinkedIn and GitHub links in `index.html`.
3. Review all experience dates and descriptions for accuracy.
4. Add your PDF resume at `assets/resume.pdf`.
5. Replace the project dashboard placeholder with your own screenshot if desired.
6. Add your real Power BI and GitHub project links.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After deployment, visit `https://YOURUSERNAME.github.io`.

GitHub Pages may take a few minutes to publish the first time.
